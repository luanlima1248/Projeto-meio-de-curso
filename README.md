Este é um projeto de Landing Page desenvolvido como trabalho de conclusão de meio de curso. O site é totalmente dedicado à franquia **Darksiders**, explorando a jornada dos Cavaleiros do Apocalipse.

---

## 🌑 Sobre o Site

O site foi construído com foco na ambientação e imersão do usuário, trazendo informações detalhadas sobre o universo onde o equilíbrio entre o Céu e o Inferno foi quebrado.

### 📜 Seções Principais:
* **Os Cavaleiros:** Uma área dedicada aos protagonistas (Guerra, Morte, Fúria e Conflito).
* **O Mundo:** Detalhes sobre a lore e os cenários devastados da franquia.
* **Contato:** Uma aba funcional para comunicação, integrando o usuário ao projeto.

## 🛠️ Tecnologias Utilizadas

Para manter a fidelidade visual e a performance do site, utilizei:

* **HTML5:** Para uma estrutura semântica e organizada.
* **CSS3:** Estilização personalizada, filtros de imagem e layout responsivo.
* **Google Fonts:** Tipografia selecionada para combinar com a estética épica do jogo.
